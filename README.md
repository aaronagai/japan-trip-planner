# Japan Trip Planner

Trip dashboard for Osaka, Japan, Oct 2026.

**Live preview:** https://aaronagai.github.io/japan-trip-planner/

## Overview

- **Destination:** Osaka, Japan
- **Dates:** 5 Oct – 11 Oct 2026
- **Pax:** Andrea & Mummy

## Features

- Expense breakdown (flights, accommodation, food, transport, utilities)
- Donut chart and contribution split
- Budget progress bars
- Expandable detail tables for each category
